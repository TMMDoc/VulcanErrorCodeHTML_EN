3.10.2 MK_AXIS_HANDWHEEL_FACTOR

It is an axis-specific MC, which allocates the individual axes to a configured hand wheel. This MC has a parameter for each application axis in which the number of the allocated hand wheel is entered. It must only be changed when more than one hand wheel is configured.
