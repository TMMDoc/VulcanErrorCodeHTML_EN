In PLC options, Select function parameters to access auto nozzle clean options.

5.5.1 Based On - The auto nozzle clean program can be activated based on the following options: i. Cutting length. ii. Number of Piercing the corresponding values are entered in the Custom parameter. 5.5.2 State of Pgm - Selects the option to when to activate the Nozzle program if the above conditions are met. i. Before start of a Program ii. During running of program after the M15 command. Depends on both the options selected above, the PLC will activate the auto nozzle cleaning program.
